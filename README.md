# Network Traffic Analyzer

A Python-based network traffic analysis tool built with Scapy. The project captures live network packets, analyzes traffic patterns, identifies commonly used TCP and UDP destination ports, and generates visual reports.

## Project Overview

The Network Traffic Analyzer was developed as a cybersecurity and networking portfolio project to gain practical experience in packet capture, network traffic analysis, protocol identification, and basic traffic monitoring.

The analyzer works with live network traffic and provides statistical insights into captured packets without attempting to decrypt encrypted application traffic.

## Features

* Live network packet capture using Scapy
* Automatic local IP detection
* TCP and UDP traffic analysis
* Incoming and outgoing traffic analysis
* IPv4 and IPv6 packet handling
* Safe handling of non-IP packets
* Unique source and destination IP counting
* Top TCP destination port analysis
* Top UDP destination port analysis
* TCP SYN packet counting
* TCP RST packet counting
* Traffic visualization using Matplotlib
* Automatic generation of traffic charts

## How It Works

The analyzer follows a simple workflow:

```text
Live Network Traffic
        ↓
Packet Capture
        ↓
Packet Analysis
        ↓
Traffic Statistics
        ↓
Visualization
        ↓
Generated Reports
```

### 1. Packet Capture

`sniffer.py` captures live network traffic for a predefined period using Scapy.

The tool automatically detects the local IPv4 address instead of relying on a hard-coded IP address.

### 2. Traffic Analysis

`analyzer.py` processes the captured packets and extracts information such as:

* TCP and UDP packet counts
* Incoming and outgoing traffic
* Source and destination IP addresses
* TCP and UDP destination ports
* TCP SYN and RST flags

The analyzer safely handles IPv4, IPv6, and non-IP packets.

### 3. Visualization

`report.py` generates charts showing:

* TCP vs UDP traffic
* Top UDP destination ports
* Top TCP destination ports
* Incoming vs outgoing traffic

## Testing and Validation

The project was tested using real network traffic on a home fiber network with more than 10 connected devices.

During the validation experiments:

* Pinterest was actively used on the analysis PC.
* Netflix was streaming on an iPad connected to the same network.
* Other connected devices were also generating background network activity through activities such as video streaming, social media, applications, reading, and gaming.

The analyzer captured traffic available to the analysis PC's network interface during the tests.

### Final 60-Second Test

The final validation run captured live traffic for approximately 60 seconds.

| Metric                   |       Result |
| ------------------------ | -----------: |
| Capture Time             | 60.1 seconds |
| Total Packets            |        8,351 |
| TCP Packets              |        1,995 |
| UDP Packets              |        6,293 |
| Incoming Packets         |        1,230 |
| Outgoing Packets         |        1,308 |
| Unique Source IPs        |           44 |
| Unique Destination IPs   |           58 |
| TCP SYN Packets          |           18 |
| TCP RST Packets          |            2 |
| Top UDP Destination Port |          443 |
| Top TCP Destination Port |          443 |

The final test also confirmed that the analyzer successfully detected the local IP address automatically.

These results demonstrate that the analyzer can process live network traffic generated by normal network activity and produce useful packet-level statistics.

> Note: The presence of a destination port does not by itself identify the exact application generating the traffic. For example, port 443 can be used by different applications and protocols.

## Installation

Clone the repository and install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Navigate to the `src` directory:

```bash
cd src
```

Run the analyzer:

```bash
python sniffer.py
```

The tool will capture network traffic, analyze the packets, display the collected statistics, and generate traffic charts.

## Requirements

* Python 3.x
* Scapy 2.7.0
* Matplotlib
* A network interface capable of capturing traffic
* Appropriate permissions for packet capture on the operating system
